# Source preservation

Owner requirement, September 13, 2026: archives must preserve instructional images alongside text to protect against link rot.

For future captures, save original source files or data, all embedded diagrams and images, and a readable offline version when needed. Preserve captions, tables, legends, and applicability information. Record original URLs, retrieval dates, and file hashes. Check all embedded assets locally. Describe incomplete captures explicitly; a live link or text-only snapshot is not a complete archive. Distinguish embedded content from links to separate publications.

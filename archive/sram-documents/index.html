SRAM DUB crank references¶

Publisher: SRAM. Retrieved: September 13, 2026. Edition: captured English digital manual and compatibility PDF; publication/revision dates have not yet been verified.

Read the preserved illustrated manual or use the original links below.

Installation manual¶

Read SRAM’s DUB Cranksets and Bottom Brackets manual.

At retrieval on September 13, 2026, this was the digital manual linked by SRAM’s DUB BSA service page. It includes installation procedures and a spacer chart with a BSA 100 mm / Fat entry. Match the instructions to the particular crank and bottom bracket; this is not a Pugsley-specific fit approval or a separate FAT4-only manual.

Compatibility chart¶

Read or download the archived DUB MTB compatibility chart.

Original PDF, published by SRAM. This chart accompanies the installation instructions; it does not replace them.

Offline illustrated manual¶

Read the archived illustrated DUB manual.

The offline edition includes all ten modules from the captured English manual, with local copies of all 51 referenced image assets, along with the text, tables, captions, tools, and symbol legend. It requires no external scripts, styles, or image requests. All variants are displayed together and applicability labels are retained.

Preservation record¶

Retrieved September 13, 2026. Published by SRAM. The compatibility PDF is preserved unchanged. The digital manual’s original embedded source data is retained unchanged; the offline reading layout is reconstructed from it, rather than a copy of SRAM’s interactive viewer. The asset manifest records source URLs, file sizes, and SHA-256 hashes.

External reference links to separate manuals and websites remain external; those separate documents are not part of this capture. The archived manual itself has its text and illustrations available offline.

# About this site

Pugsley Wiki is an independent collection of Surly Pugsley source material. It is not an official Surly publication.

Historical summaries identify their sources and the period they describe. Archived documents remain separate from editorial summaries; preserving a document does not verify every statement in it.

Earlier guides have been withdrawn while the site is reduced to material it can support. New technical guidance needs documentation for the specific frame, fork and components involved.
